# Trade-Forex สมุดเทรด

เว็บแอพสำหรับบันทึกและวิเคราะห์การเทรด **Forex ทองคำ และบิตคอยน์** หน้าจอเป็นภาษาไทย ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ รองรับธีมสว่างและมืด

ไม่ต้องติดตั้งอะไร ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก

## ทำอะไรได้บ้าง

| หน้า | สิ่งที่มี |
|---|---|
| **ภาพรวม** | กำไร/ขาดทุนสุทธิ, Win rate, Profit factor, ค่าเฉลี่ยต่อเทรด, Max drawdown, R เฉลี่ย, กราฟเส้นเงินทุน, ผลแยกตามสินทรัพย์, ข้อสังเกตเด่น, เทรดล่าสุด |
| **บันทึกเทรด** | เพิ่ม แก้ไข ลบเทรด ค้นหา นำเข้าและส่งออกไฟล์ |
| **วิเคราะห์** | ข้อสังเกตอัตโนมัติ, สถิติโดยละเอียด, กราฟรายเดือน, Drawdown, แยกตามคู่เงิน กลยุทธ์ วันในสัปดาห์ ช่วงตลาด ระยะเวลาถือ, การกระจายของ R, ตารางพฤติกรรม (ฝั่ง การทำตามแผน อารมณ์), ปฏิทินกำไร/ขาดทุนรายวัน |
| **เครื่องมือ** | คำนวณขนาด Lot จากความเสี่ยง, ตั้งทุนเริ่มต้น, สำรองและกู้คืนข้อมูล |

ตัวกรองช่วงเวลา (ทั้งหมด / 7 / 30 / 90 วัน / ปีนี้) และสินทรัพย์ (Forex / ทองคำ / บิตคอยน์) มีผลกับทุกตัวเลขและทุกกราฟพร้อมกัน ทุกกราฟกด “ดูตาราง” เพื่อดูตัวเลขเดียวกันเป็นตารางได้

เมื่อยังไม่มีเทรด แอพจะแสดงเทรดสมมติ 72 รายการให้ดูเป็นตัวอย่าง ตัวอย่างไม่ถูกบันทึก และจะหายไปเองเมื่อบันทึกเทรดแรก

## วิธีใช้

**เปิดจากเครื่อง:** ดาวน์โหลดโฟลเดอร์นี้ แล้วเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์

**เปิดผ่านเว็บ (GitHub Pages):** ไปที่ Settings → Pages ของ repo เลือก Deploy from a branch แล้วเลือก branch ที่มีไฟล์เหล่านี้กับโฟลเดอร์ `/ (root)`

**รันเซิร์ฟเวอร์ในเครื่อง:**

```bash
npm start        # แล้วเปิด http://localhost:8080
```

## การบันทึกเทรด

กรอกคู่เงิน ฝั่ง (Buy/Sell) ขนาด Lot ราคาเข้า และเวลาเปิด ถ้าออเดอร์ปิดแล้วให้ใส่ราคาออก เวลาปิด และกำไร/ขาดทุน ออเดอร์ที่ยังไม่ปิดบันทึกไว้ก่อนได้ แต่จะยังไม่ถูกนับในสถิติ

Stop loss, Take profit, กลยุทธ์, อารมณ์ตอนเข้า, การทำตามแผน และโน้ต ไม่บังคับ แต่ยิ่งกรอกครบ หน้าวิเคราะห์ยิ่งบอกได้มาก เช่น ต้องมี Stop loss จึงจะคิดผลลัพธ์เป็น R ได้

### กำไร/ขาดทุนที่คำนวณอัตโนมัติ

แอพคำนวณกำไร/ขาดทุนจากราคาให้เป็น **ดอลลาร์สหรัฐ** โดยใช้ขนาดสัญญามาตรฐาน:

| สินทรัพย์ | 1 Lot | 1 pip |
|---|---|---|
| Forex | 100,000 หน่วยของสกุลหลัก | 0.0001 (คู่เยน 0.01) |
| ทองคำ (XAUUSD) | 100 ออนซ์ | 0.10 |
| บิตคอยน์ (BTCUSD) | 1 BTC | 1.00 |

- คู่ที่ลงท้ายด้วย USD (EURUSD, XAUUSD, BTCUSD) คำนวณตรง
- คู่ที่ขึ้นต้นด้วย USD (USDJPY, USDCHF, USDCAD) แปลงกลับเป็นดอลลาร์ด้วยราคาออก
- คู่ไขว้ (EURJPY, GBPJPY ฯลฯ) ต้องใช้อัตราแลกเปลี่ยนอีกคู่ แอพจึงไม่คำนวณให้ ให้ใส่ตัวเลขตามที่โบรกเกอร์แสดง

ตัวเลขที่คำนวณแก้ทับได้เสมอ ถ้าโบรกเกอร์ของคุณใช้ขนาดสัญญาต่างจากนี้ หรือบัญชีไม่ใช่ดอลลาร์ ให้ใส่กำไร/ขาดทุนตามที่โบรกเกอร์แสดง

## ข้อมูลเก็บที่ไหน

เทรดถูกเก็บใน **เบราว์เซอร์ของคุณเอง** (localStorage) ไม่ถูกส่งไปที่ไหน ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไป จึงควรกด **สำรองข้อมูล (.json)** ในหน้าเครื่องมือเป็นระยะ แล้วใช้ **กู้คืน / นำเข้าไฟล์** เมื่อต้องการย้ายเครื่อง

เมื่อเปิดแอพในรูปแบบ Claude artifact เทรดจะถูกเก็บไว้กับบัญชี Claude ของผู้ใช้แทน (เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน และผู้อื่นที่เปิดหน้าเดียวกันจะไม่เห็น)

## นำเข้าและส่งออก CSV

ส่งออกได้จากหน้าบันทึกเทรดหรือหน้าเครื่องมือ ไฟล์ที่ได้มีคอลัมน์:

```
openTime, closeTime, symbol, asset, side, lots, entry, exit, sl, tp, fees, pnl, strategy, emotion, plan, notes
```

การนำเข้าต้องมีอย่างน้อยคอลัมน์ `symbol` และ `entry` ชื่อคอลัมน์แบบตารางประวัติของ MT4/MT5 ก็อ่านได้ (`Open Time`, `Type`, `Size`, `Item`, `Price`, `S / L`, `T / P`, `Close Time`, `Commission`, `Swap`, `Profit`) โดยแถวที่ไม่ใช่ออเดอร์ซื้อขาย เช่น ฝากเงิน จะถูกข้าม และเทรดที่มีอยู่แล้วจะไม่ถูกเพิ่มซ้ำ

> การอ่านคอลัมน์แบบ MT4/MT5 ทดสอบกับไฟล์ที่จัดรูปแบบตามหัวตารางข้างต้น ยังไม่ได้ทดสอบกับไฟล์ที่ส่งออกจากโบรกเกอร์จริงทุกราย ถ้าไฟล์ของคุณนำเข้าไม่ได้ ให้เทียบหัวคอลัมน์กับไฟล์ที่ส่งออกจากแอพนี้

## สำหรับนักพัฒนา

ไม่มีขั้นตอน build แอพเป็น HTML, CSS และ JavaScript ล้วน

```
index.html              หน้าเว็บและฟอร์มทั้งหมด
css/app.css             สไตล์และโทนสีทั้งสองธีม
js/core.js              ตรรกะล้วน: สินทรัพย์ กำไร/ขาดทุน สถิติ ข้อสังเกต CSV การจัดรูปแบบ
js/sample.js            ตัวสร้างเทรดตัวอย่าง
js/store.js             การเก็บข้อมูล (localStorage หรือที่เก็บของ Claude artifact)
js/charts.js            ตัวสร้างกราฟบน Chart.js
js/app.js               หน้าจอและการโต้ตอบ
vendor/chart.umd.min.js Chart.js 4.4.1 (MIT)
scripts/build-artifact.mjs  รวมเป็นหน้าเดียวสำหรับเผยแพร่เป็น Claude artifact
tests/                  ชุดทดสอบ
```

```bash
npm test               # ทดสอบการคำนวณและสถิติ (Node.js 20+ ไม่ต้องติดตั้งอะไรเพิ่ม)
npm run test:browser   # ทดสอบในเบราว์เซอร์จริง ต้องมี Playwright (npm i -D playwright)
npm run build:artifact # สร้าง dist/trade-forex.html
```
