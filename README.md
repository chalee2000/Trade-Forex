# Trade-Forex สมุดเทรด

เว็บแอพสำหรับ**วิเคราะห์กราฟ**และ**บันทึกการเทรด** Forex ทองคำ และบิตคอยน์ หน้าจอเป็นภาษาไทย ใช้ได้ทั้งบนคอมพิวเตอร์และมือถือ รองรับธีมสว่างและมืด

ไม่ต้องติดตั้งอะไร ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก

## ทำอะไรได้บ้าง

| หน้า | สิ่งที่มี |
|---|---|
| **วิเคราะห์ตลาด** | กราฟแท่งเทียนพร้อม EMA20/EMA50, RSI, MACD, คะแนนรวมของอินดิเคเตอร์ (−100 ถึง +100), แนวโน้ม โมเมนตัม ความผันผวน, แนวรับ-แนวต้านจากจุดกลับตัว, แผนตัวอย่างตามสูตร (เข้า / SL / TP) ที่ส่งต่อไปคำนวณ Lot หรือบันทึกเป็นเทรดได้ |
| **ภาพรวม** | กำไร/ขาดทุนสุทธิ, Win rate, Profit factor, ค่าเฉลี่ยต่อเทรด, Max drawdown, R เฉลี่ย, กราฟเส้นเงินทุน, ผลแยกตามสินทรัพย์, ข้อสังเกตเด่น, เทรดล่าสุด |
| **บันทึกเทรด** | เพิ่ม แก้ไข ลบเทรด ค้นหา นำเข้าและส่งออกไฟล์ |
| **สถิติ** | ข้อสังเกตอัตโนมัติ, สถิติโดยละเอียด, กราฟรายเดือน, Drawdown, แยกตามคู่เงิน กลยุทธ์ วันในสัปดาห์ ช่วงตลาด ระยะเวลาถือ, การกระจายของ R, ตารางพฤติกรรม (ฝั่ง การทำตามแผน อารมณ์), ปฏิทินกำไร/ขาดทุนรายวัน |
| **เครื่องมือ** | คำนวณขนาด Lot จากความเสี่ยง, ตั้งทุนเริ่มต้น, สำรองและกู้คืนข้อมูล |

ตัวกรองช่วงเวลา (ทั้งหมด / 7 / 30 / 90 วัน / ปีนี้) และสินทรัพย์ (Forex / ทองคำ / บิตคอยน์) มีผลกับทุกตัวเลขและทุกกราฟพร้อมกัน ทุกกราฟกด “ดูตาราง” เพื่อดูตัวเลขเดียวกันเป็นตารางได้

เมื่อยังไม่มีเทรด แอพจะแสดงเทรดสมมติ 72 รายการให้ดูเป็นตัวอย่าง ตัวอย่างไม่ถูกบันทึก และจะหายไปเองเมื่อบันทึกเทรดแรก

## หน้าวิเคราะห์ตลาด: ราคามาจากไหน

เลือกสินทรัพย์ (EUR/USD, GBP/USD, USD/JPY, AUD/USD, USD/CHF, USD/CAD, ทองคำ, Bitcoin) และกรอบเวลา (M15, H1, H4, D1) แล้วแอพจะคำนวณทุกอย่างในเบราว์เซอร์ของคุณ ข้อมูลราคามาได้สามทาง:

1. **ราคาสด** เมื่อเปิดแอพเป็นเว็บทั่วไป (เปิดไฟล์จากเครื่อง หรือผ่าน GitHub Pages) แอพดึงแท่งเทียนจาก API สาธารณะของ Kraken และใช้ Binance เป็นตัวสำรองสำหรับ Bitcoin กับทองคำ ไม่ต้องมีบัญชีหรือคีย์
   - ทองคำไม่มีแหล่งราคา XAU/USD ที่เปิดให้เบราว์เซอร์ดึงได้ฟรี แอพจึงใช้ราคาโทเคนทอง **PAXG** แทน ซึ่งเคลื่อนไหวใกล้เคียงกันแต่ไม่เท่ากันทุกจุด และแอพแจ้งไว้บนหน้าจอทุกครั้ง
   - ราคาจากแหล่งเหล่านี้อาจต่างจากราคาของโบรกเกอร์คุณเล็กน้อย
2. **ไฟล์ราคา** กด “นำเข้าไฟล์ราคา” แล้วเลือกไฟล์ CSV ที่ส่งออกจาก MT4 (History Center), MT5 หรือ TradingView ต้องมีอย่างน้อย 60 แท่ง
3. **ราคาตัวอย่าง** ถ้าไม่มีทั้งสองอย่าง แอพจะแสดงราคาที่สร้างขึ้นเพื่อสาธิต พร้อมป้าย “ตัวอย่าง” กำกับชัดเจน และปิดปุ่มส่งต่อแผนไว้
   - ราคาปิดล่าสุดของกราฟตัวอย่างตั้งตามราคาจริงที่เผยแพร่ช่วง 13–16 พ.ย. 2026 (ค่าเงินจากหน้าค่าเงินของ Bloomberg วันที่ 13 พ.ย., ทองคำจาก TradingView และ Bitcoin จาก OKX วันที่ 16 พ.ย.) แต่แท่งเทียนก่อนหน้าและอินดิเคเตอร์เป็นข้อมูลสมมติ ค่าเหล่านี้เป็นภาพนิ่ง ไม่อัปเดตเอง แก้ได้ที่ `REFERENCE` ใน `js/sample.js`

> ส่วนดึงราคาสดทดสอบกับข้อมูลจำลองที่มีรูปแบบเดียวกับคำตอบของ API แล้ว แต่ยังไม่ได้ทดสอบกับเซิร์ฟเวอร์จริง เพราะสภาพแวดล้อมที่ใช้พัฒนาต่อออกไปยังแหล่งข้อมูลเหล่านั้นไม่ได้ ถ้าโหลดไม่สำเร็จ แอพจะแจ้งและแสดงราคาตัวอย่างแทน

### ตั้งราคาให้ตรงโบรกเกอร์

ราคาสดจากแหล่งข้อมูลสาธารณะไม่มีทางตรงกับโบรกเกอร์ของคุณทุกจุด (แต่ละโบรกเกอร์มีราคาของตัวเอง และทองคำใช้ PAXG แทน) เมื่อใช้ราคาสด กด **"ตั้งให้ตรงราคาโบรกเกอร์"** ใต้ปุ่มเลือกสินทรัพย์ แล้วใส่ราคาที่เห็นใน MT4/MT5 ตอนนั้น แอพจะเลื่อนกราฟทั้งเส้นให้ราคาล่าสุดเท่ากับราคานั้น (ไม่เกิน ±2%) ค่าที่ตั้งจำไว้ในเบราว์เซอร์แยกตามสินทรัพย์ ส่วนต่างเปลี่ยนไปตามเวลา จึงควรตั้งใหม่เป็นระยะ

### คะแนนรวมคิดอย่างไร

คะแนนเป็นผลรวมถ่วงน้ำหนักของหกส่วน แต่ละส่วนมีค่าตั้งแต่ −1 (หนุนขาลง) ถึง +1 (หนุนขาขึ้น): ราคาเทียบ EMA200 (20), EMA20 เทียบ EMA50 (20), ความชันของ EMA50 (15), ฮิสโตแกรม MACD (15), RSI เทียบ 50 (15), ราคาเทียบ EMA20 (15) โดยวัดระยะเป็นจำนวนเท่าของ ATR ถ้า ADX ต่ำกว่า 18 (ไม่มีเทรนด์) คะแนนจะถูกลดลง 30% คะแนนเกิน ±20 ถือว่าเอียงไปทางนั้น เกิน ±50 ถือว่าชัด

### จุดเข้า-ออก

การ์ด "จุดเข้า-ออก" บอกทั้งฝั่ง **Buy** และ **Sell** (★ คือฝั่งที่ตรงกับแนวโน้ม) แต่ละฝั่งมี:

- **จุดเข้าและโซนเข้า**: ถ้าเป็นฝั่งตามแนวโน้มและราคายังไม่วิ่งไกลจาก EMA20 (ไม่เกิน 1 ATR และ RSI ยังไม่สุดเขต) ให้เข้าที่ราคาปัจจุบัน ไม่อย่างนั้นให้ตั้งรอที่จุดย่อ/เด้งที่ใกล้ที่สุด ได้แก่ แนวรับ-แนวต้าน, EMA20 (ฝั่งตามแนวโน้ม) หรือขอบ Bollinger (ฝั่งอื่น)
- **Stop loss**: เลยแนวที่ป้องกันจุดเข้าไป 0.4 ATR หรือ 1.5 ATR ถ้าไม่มีแนวใกล้ ๆ โดยบังคับระยะไว้ที่ 0.8–3 ATR
- **TP1 / TP2 / TP3**: วางก่อนถึงแนวถัดไปเล็กน้อย (0.1 ATR) แต่ละเป้าต้องได้อย่างน้อย 1R และห่างกันอย่างน้อย 0.75R ถ้าไม่มีแนวในระยะ ใช้ 1.5R / 2.5R / 3.5R

ประเภทของแต่ละฝั่ง: **ตามแนวโน้ม** (คะแนนเอียงมาทางนี้), **สวนแนวโน้ม** (ความเสี่ยงสูงกว่า) หรือ **เล่นในกรอบ** (คะแนนไม่เกิน ±20) เส้นของฝั่งที่เลือกจะวาดบนกราฟ และปุ่ม "คำนวณขนาด Lot" กับ "บันทึกเป็นเทรด" ใช้ TP2 เป็นเป้าหลัก ทั้งหมดเป็นสูตรตายตัว ไม่ได้ทำนายราคา และไม่ใช่คำแนะนำการลงทุน เมื่อเป็นราคาตัวอย่าง การ์ดจะเตือนว่าตัวเลขไม่ใช่จุดเข้าเทรดจริงและปิดปุ่มส่งต่อไว้

### AI อ่านกราฟและสรุปผลเทรด

เมื่อเปิดแอพในรูปแบบ Claude artifact จะมีอีกสองอย่างที่ใช้ Claude ในบัญชีของผู้เปิดเอง:

- **ให้ AI อ่านกราฟของคุณ** อัปโหลดภาพหน้าจอกราฟจาก MT4/MT5/TradingView แล้ว Claude จะอ่าน**ราคาปัจจุบันในภาพ** แนวรับ-แนวต้าน และแผนฝั่ง Buy และ Sell (จุดเข้า SL TP1 TP2) พร้อมฝั่งที่ได้เปรียบกว่า แอพตรวจตัวเลขก่อนแสดง: แผนที่ SL หรือเป้าอยู่ผิดฝั่งของจุดเข้า หรือราคาที่ห่างจากราคาปัจจุบันเกิน 25% จะไม่ถูกแสดง และ R:R คำนวณโดยแอพเอง
- **ให้ AI สรุปการเทรดของคุณ** (หน้าสถิติ เมื่อมีเทรดที่ปิดแล้วอย่างน้อย 5 เทรด) ส่งเฉพาะตัวเลขสถิติ ไม่ส่งโน้ต

ทั้งสองอย่างไม่มีในเวอร์ชันที่เปิดเป็นเว็บทั่วไป


## การบันทึกเทรด

กรอกคู่เงิน ฝั่ง (Buy/Sell) ขนาด Lot ราคาเข้า และเวลาเปิด ถ้าออเดอร์ปิดแล้วให้ใส่ราคาออก เวลาปิด และกำไร/ขาดทุน ออเดอร์ที่ยังไม่ปิดบันทึกไว้ก่อนได้ แต่จะยังไม่ถูกนับในสถิติ

Stop loss, Take profit, กลยุทธ์, อารมณ์ตอนเข้า, การทำตามแผน และโน้ต ไม่บังคับ แต่ยิ่งกรอกครบ หน้าวิเคราะห์ยิ่งบอกได้มาก เช่น ต้องมี Stop loss จึงจะคิดผลลัพธ์เป็น R ได้

### กำไร/ขาดทุนที่คำนวณอัตโนมัติ

แอพคำนวณกำไร/ขาดทุนจากราคาให้เป็น **ดอลลาร์สหรัฐ** โดยใช้ขนาดสัญญามาตรฐาน:

| สินทรัพย์ | 1 Lot | 1 pip |
|---|---|---|
| Forex | 100,000 หน่วยของสกุลหลัก | 0.0001 (คู่เยน 0.01) |
| ทองคำ (XAUUSD) | 100 ออนซ์ | 0.10 |
| บิตคอยน์ (BTCUSD) | 1 BTC | 1.00 |

- คู่ที่ลงท้ายด้วย USD (EURUSD, XAUUSD, BTCUSD) คำนวณตรง
- คู่ที่ขึ้นต้นด้วย USD (USDJPY, USDCHF, USDCAD) แปลงกลับเป็นดอลลาร์ด้วยราคาออก
- คู่ไขว้ (EURJPY, GBPJPY ฯลฯ) ต้องใช้อัตราแลกเปลี่ยนอีกคู่ แอพจึงไม่คำนวณให้ ให้ใส่ตัวเลขตามที่โบรกเกอร์แสดง

ตัวเลขที่คำนวณแก้ทับได้เสมอ ถ้าโบรกเกอร์ของคุณใช้ขนาดสัญญาต่างจากนี้ หรือบัญชีไม่ใช่ดอลลาร์ ให้ใส่กำไร/ขาดทุนตามที่โบรกเกอร์แสดง

## ข้อมูลเก็บที่ไหน

เทรดถูกเก็บใน **เบราว์เซอร์ของคุณเอง** (localStorage) ไม่ถูกส่งไปที่ไหน ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะไม่ตามไป จึงควรกด **สำรองข้อมูล (.json)** ในหน้าเครื่องมือเป็นระยะ แล้วใช้ **กู้คืน / นำเข้าไฟล์** เมื่อต้องการย้ายเครื่อง

เมื่อเปิดแอพในรูปแบบ Claude artifact เทรดจะถูกเก็บไว้กับบัญชี Claude ของผู้ใช้แทน (เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน และผู้อื่นที่เปิดหน้าเดียวกันจะไม่เห็น)

## นำเข้าและส่งออก CSV

ส่งออกได้จากหน้าบันทึกเทรดหรือหน้าเครื่องมือ ไฟล์ที่ได้มีคอลัมน์:

```
openTime, closeTime, symbol, asset, side, lots, entry, exit, sl, tp, fees, pnl, strategy, emotion, plan, notes
```

การนำเข้าต้องมีอย่างน้อยคอลัมน์ `symbol` และ `entry` ชื่อคอลัมน์แบบตารางประวัติของ MT4/MT5 ก็อ่านได้ (`Open Time`, `Type`, `Size`, `Item`, `Price`, `S / L`, `T / P`, `Close Time`, `Commission`, `Swap`, `Profit`) โดยแถวที่ไม่ใช่ออเดอร์ซื้อขาย เช่น ฝากเงิน จะถูกข้าม และเทรดที่มีอยู่แล้วจะไม่ถูกเพิ่มซ้ำ

> การอ่านคอลัมน์แบบ MT4/MT5 ทดสอบกับไฟล์ที่จัดรูปแบบตามหัวตารางข้างต้น ยังไม่ได้ทดสอบกับไฟล์ที่ส่งออกจากโบรกเกอร์จริงทุกราย ถ้าไฟล์ของคุณนำเข้าไม่ได้ ให้เทียบหัวคอลัมน์กับไฟล์ที่ส่งออกจากแอพนี้

## สำหรับนักพัฒนา

ไม่มีขั้นตอน build แอพเป็น HTML, CSS และ JavaScript ล้วน

```
index.html              หน้าเว็บและฟอร์มทั้งหมด
css/app.css             สไตล์และโทนสีทั้งสองธีม
js/core.js              ตรรกะล้วน: สินทรัพย์ กำไร/ขาดทุน สถิติ ข้อสังเกต CSV การจัดรูปแบบ
js/ta.js                ตรรกะล้วน: อินดิเคเตอร์ แนวรับ-แนวต้าน การอ่านสัญญาณ ตัวอ่านไฟล์ราคา
js/market.js            ดึงแท่งเทียนจาก Kraken และ Binance
js/sample.js            ตัวสร้างเทรดและราคาตัวอย่าง
js/store.js             การเก็บข้อมูล (localStorage หรือที่เก็บของ Claude artifact)
js/charts.js            ตัวสร้างกราฟบน Chart.js
js/app.js               หน้าจอและการโต้ตอบ
vendor/chart.umd.min.js Chart.js 4.4.1 (MIT)
scripts/build-artifact.mjs  รวมเป็นหน้าเดียวสำหรับเผยแพร่เป็น Claude artifact
tests/                  ชุดทดสอบ
```

```bash
npm test               # ทดสอบการคำนวณ สถิติ และอินดิเคเตอร์ (Node.js 20+ ไม่ต้องติดตั้งอะไรเพิ่ม)
npm run test:browser   # ทดสอบในเบราว์เซอร์จริง ต้องมี Playwright (npm i -D playwright)
npm run build:artifact # สร้าง dist/trade-forex.html
```

## ข้อควรทราบ

แอพนี้เป็นเครื่องมือช่วยอ่านกราฟและสรุปสถิติการเทรดของคุณเอง ไม่ได้ส่งคำสั่งซื้อขาย สัญญาณและคะแนนคำนวณจากอินดิเคเตอร์ตามสูตร ไม่ได้ทำนายราคา และไม่ใช่คำแนะนำการลงทุน
